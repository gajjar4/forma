# Security

Forma runs on your Mac and reads and writes the folders you open as boards.
If you find a way for a board, a live card or a link to reach beyond that,
or anything else that puts someone's files at risk, please report it
privately: use **Report a vulnerability** on the repository's Security tab,
not a public issue.

You'll hear back within a week, and the fix will credit you unless you'd
rather it didn't.
