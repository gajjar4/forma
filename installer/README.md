# forma-board

Installs [Forma](https://github.com/gajjar4/forma) on your Mac, or
updates it:

```bash
npx forma-board
```

It downloads the latest Forma.app from the GitHub releases, puts it in your
Applications folder and opens it. Run it again any time to update. Your
boards live in `~/Documents/Forma` and are never touched.

Needs a Mac and Node 18 or later.
